PUBLISH FREE WITH GITHUB PAGES
1. Sign in or create a free account at https://github.com/
2. Create a new public repository. Suggested name: smb-venture-website
3. Upload index.html and the assets folder (keep the folder structure unchanged).
4. Open the repository's Settings > Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The site address will normally be:
   https://fakhryafendi.github.io/smb-venture-website/

NOTES
- No paid hosting is required for GitHub Pages on a public repository.
- Replace YOUR-GITHUB-USERNAME with your GitHub username.
- The website follows the company profile's content and navy/gold corporate style, adapted into a responsive single-page website.
- Before publishing, please verify partner names, registrations, claims and contact details. Partner logos and CEO portrait were not included because separate image files were not provided.
